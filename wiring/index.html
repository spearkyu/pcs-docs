트렁크

배치 확정
통합 함체 1개 제작. 보드 A·B·C와 2채널 릴레이 1개(보드 B 제어 · CH1 UVC, CH2 PDLC)를 함체 하나에 넣습니다. 보드 3개는 USB 허브 없이 미니 PC에 직접 꽂습니다(USB-A 1, USB-C 2). 고급스러운 마감과 사용 편리성을 최대한 고려해 주세요.
  • 마감: 차량 내장재와 어울리는 색·질감, 모서리 라운드, 나사와 케이블 노출 최소화
  • 점검: 덮개를 쉽게 열 수 있어 보드 점검·교체가 편하게
  • 펌웨어: 보드 USB-C에 노트북을 연결할 수 있는 접근 경로
  • 배선: 케이블 인출구(그로밋), 커넥터로 분리 가능, 함체 안 배선 라벨
  • 발열·고정: 통풍구 확보, 주행 중 움직이지 않되 탈거 가능하게
  • 크기: 내부 부품 실물 기준으로 결정 (도면 치수 없음)
  • 파워뱅크는 이동하지 않게 고정하고 전원 버튼·출력 포트·충전 단자에 손이 닿게
  • 미니 PC·PDLC 제어기·어댑터 고정과 선 정리, 미니 PC 통풍 확보
  • 짐 공간을 최대한 남기는 배치 (그림의 트렁크 내부 배치는 예시)

1열

위치 확정
  • 공기청정기: 좌석 사이 암레스트 위 고정, 미끄럼 방지·탈거 가능. 암레스트 수납함 열 때 간섭 확인 (V-01·V-03)
  • 디퓨저: 컵홀더 거치, 흔들림 방지 (V-02·V-04)
  • IR 송신모듈: 각 기기 IR 수신부 가까이 부착하고 겉으로 드러나지 않게 정리
  • UVC 모듈: 조수석 시트 하단에 2열 쪽을 향하게 브래킷 고정, 시트 앞뒤 이동 간섭 확인 (V-06)
  • 전원선·신호선은 콘솔 측면·하부로 숨김

2열

일부 미정
  • PDLC 필름: 우측 뒷창 시공, 제어기 선을 도어 안으로 인입 (V-07)
  • LED 스트랩: 우측 뒷창 주변 부착, 부착 형태는 협의 (V-08·V-09)
  • SEN66: 위치 미정. 승객 호흡 높이 근처에서 센서 흡배기구를 막지 않고 에어컨 바람이 직접 닿지 않는 곳 (그림은 1열 콘솔 후면 가정, V-05)

공통

  • 배선은 내장재 안쪽으로 숨기고 노출을 최소화
  • 경로는 작업자 판단, 표의 도착 지점까지만 오면 됨
  • 각 선 양 끝에 배선 ID 라벨 (V-01 등)
  • 기기 쪽 끝은 커넥터로 분리 가능하게
  • 길이는 추정값이니 실차에서 여유 있게 재단
  • 후방센서·빔프로젝터는 위치 미정이라 확정 후 추가 요청

전원·통신

트렁크 파워뱅크가 모든 기기 전원을 공급하고, 제어 보드 3개는 미니 PC USB에 직접 꽂아 통신과 5V를 함께 받습니다 (보드 A: USB-A, 보드 B·C: USB-C).

      사용 단자

      행을 누르면 아래 "전체 단자 배열"에서 해당 단자가 강조됩니다.

      전체 단자 배열 보기 (44P 터미널 어댑터)
      • GPIO35·36·37은 Octal PSRAM이 쓰므로 배선하지 않습니다. GPIO0·3·45·46은 부팅 스트래핑 핀, GPIO19·20은 USB D−/D+입니다.
      • 3.3V 단자 하나에 IR 송신모듈 2개와 SEN66(내장 팬 포함)이 함께 물려 있습니다. 문서는 SEN66 전용 레귤레이터를 권장했으니 실측 전류를 확인할 항목으로 남깁니다.
      • SEN66 케이블 실제 선 색은 아직 받지 못해 도면 색으로만 구분했습니다.
